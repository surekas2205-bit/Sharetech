# ResourceShare — Complete Demo Package

## Included
- `index.html`: mobile-friendly standalone web app.
- `PROJECT_DOCUMENTATION.md`: project explanation and limitations.
- `TESTING_CHECKLIST.md`: step-by-step demo test.

## Open on Android
1. Download and extract `ResourceShare_Full.zip`.
2. Open the extracted folder in Files.
3. Tap `index.html` and choose Chrome.
4. Try Discover → Request → Owner desk → Approve → Check-in → Return → Activity history.

If Android does not open the HTML file correctly, publish it through a static host such as GitHub Pages or Netlify. You must sign in and publish it yourself; this package does not automatically create a public URL.

## Important limitations
This is a front-end demo with browser-local storage. It has no server database, real login, server-side roles, institutional verification, or multi-user syncing. Use fictional data only.
